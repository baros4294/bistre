# Spec 08 — Custom Sepia Book UI (Pure `package:flutter/widgets.dart`)

## 1. Zero UI Libraries & Mechanical Enforcement
`apps/bistre_app` imports ONLY `package:flutter/widgets.dart` (plus `foundation`, `rendering`, `services`, `painting`). Importing `package:flutter/material.dart`, `package:flutter/cupertino.dart`, `package:material_ui`, `package:cupertino_ui`, `package:flutter_localizations`, `package:google_fonts`, third-party state frameworks, or direct HTTP/SQL libraries is a compile-time static analysis error enforced by `tools/bistre_lints` (`bistre_forbid_ui_kits`), alongside `bistre_forbid_hardcoded_ui_strings`, `bistre_forbid_layout_animations`, `bistre_forbid_raw_colors`, and `bistre_forbid_non_directional_geometry`. The layout-animation rule also rejects `SizeTransition`, `AnimatedCrossFade`, `AnimatedDefaultTextStyle`, and `AnimatedFractionallySizedBox`; the directional rule also rejects `Positioned(left:/right:)` and `TextAlign.left/right`. `just i18n-check` rejects the banned UI words in every locale and the DESIGN.md §9 glossary terms in English. Visual tokens, typography, and the 10 Ink Primitives are governed exclusively by [`docs/design/DESIGN.md`](../design/DESIGN.md).

## 2. Pure-Widgets Ergonomics & Cross-Platform Controls
- **Root Shell**: `WidgetsApp` configured with explicit `color`, `textStyle`, `localizationsDelegates`, `locale`, `supportedLocales`, `builder` injecting `BistreTheme` + `BistreLocalizations` + `Directionality`.
- **Selection & Cross-Span LaTeX Copy**: Wrap thread feeds in `SelectableRegion` with custom `BistreSelectionControls` (copy / select all toolbar rendered via `FolioOverlay` / `OverlayPortal`, zero Material toolbar). Every LaTeX widget wraps inside `SelectionContainer.disabled` + a custom `Selectable` (`BistreMathSelectable`) returning verbatim `$...$` / `$$...$$` source text on sweep copy (preventing Flutter `WidgetSpan` drop bug `#160510` & flicker `#179527`).
- **IME Composition Safety**: `QuillInput` wraps `EditableText` directly, never modifies `controller.text` while `controller.value.composing.isValid` (protecting Vietnamese Telex/VNI and CJK IME composition), never sets `enableSuggestions: false` on prose inputs, and uses `Characters` grapheme indexing.
- **Live-Stream Scroll & Leaf Streaming**: the feed is a full-width `CustomScrollView` whose items each center a `ConstrainedBox(maxWidth: readingWidth)` (`_ReadingColumn`), so the mouse wheel scrolls from the empty page margins; a chat opens anchored at its newest message; `UserScrollNotification` unpins auto-follow on manual upward scroll and re-pins within `24px` of the tail. Stream deltas update only `LiveTurnNotifier` (`apps/bistre_app/lib/features/shell/live_turn_notifier.dart`), read by the single streaming item through a `ValueListenableBuilder` inside a `RepaintBoundary`; `FolioController` (shell, header, sidebar) is not notified per delta (regression-tested in `apps/bistre_app/test/anti_pattern_regression_test.dart`).
- **Code Fences**: soft-wrap follows `AppSettings.code_wrap_mode` (`auto` wraps below 640 px, `on`, `off`) with a per-fence toggle kept in `CodeWrapScope` so it survives virtualization. Fences render as independent `kCodeChunkLines` (8-line) chunks, each a highlighted `Text.rich` behind its own `RepaintBoundary`; while a reply streams, finished chunks keep the identical widget instance, so only the growing tail chunk is re-highlighted, laid out, and repainted. Highlighting runs per chunk, so a block comment or string spanning a chunk boundary is tinted per chunk (the source text, selection, and copy stay exact). `MarkdownFolioView` keeps up to four open-fence parse memos: while a reply grows inside an unterminated fence and no new fence marker or `\r` arrives, the block list is extended without re-splitting the message; any marker falls back to the full parser (`apps/bistre_app/test/streaming_markdown_test.dart`).
- **Android 15/16 Edge-to-Edge**: `MainActivity.kt` invokes `WindowCompat.setDecorFitsSystemWindows(window, false)`; `ParchmentScaffold` maps physical `MediaQuery.paddingOf(context)` left/right cutouts according to `Directionality.of(context)` (preventing RTL cutout inversion) and computes bottom avoidance via `max(MediaQuery.paddingOf(context).bottom, MediaQuery.viewInsetsOf(context).bottom)` so bottom chrome never jumps when floating/docked keyboards open.
- **State Management**: Built-in `ChangeNotifier` / `ValueNotifier` + `InheritedNotifier` + `ListenableBuilder` only (zero third-party state frameworks). The root `WidgetsApp` listens only to `FolioController.appearance` (an `AppAppearance` value: theme, accent, typography, reduced effects) and the locale, and reuses the resolved theme until that value changes; the window title follows the controller through a listener. Toasts, search (query, scope, results), the Draft saved label, and the sidebar filter each have their own notifier read only by the widget that shows them, so none of them rebuilds the shell; the engine's draft-saved echo changes nothing and notifies nothing. Thread switches carry a generation number and search carries a sequence number (150 ms debounce), so a slower, older response never replaces newer state. Chats still inside their Undo window are deleted when the app pauses or closes. Committed markdown is parsed once per text (256-entry LRU in `MarkdownFolioView`), and messages never replay an entrance animation. Tests: `apps/bistre_app/test/anti_pattern_regression_test.dart`.
- **Plain Everyday Copy & Vertical-First Restraint**: User-facing strings across `en`, `vi`, and `ar` strictly use everyday language (`Send`, `New chat`, `Recent`, `Pinned`, `You`, `Light`/`Dark`, `Document`/`Bubbles`, `Settings`, `Providers & Keys`) with zero literary jargon (`Inscribe`, `Folio`, `Passage`, `Author`, `Parchment`, `Candlelight`, `Wax Seal`). Navigation, providers, assistants, topics, chats, and settings compose from clean vertical lists, reserving horizontal segmented tracks strictly for 2–4 compact mutually exclusive toggles.
- **Windows 11 Native Desktop Host (`apps/bistre_app/windows/runner/`)**: Uses a true native Win32 frame (`Bistre`) with DWM Sepia titlebar tinting (`DWMWA_CAPTION_COLOR`, `DWMWA_TEXT_COLOR`, `DWMWA_BORDER_COLOR`, `DWMWA_USE_IMMERSIVE_DARK_MODE`, `DWMWCP_ROUND`), preserves native Windows 11 minimize/restore glide animations (`SIZE_MINIMIZED` guard in `WM_SIZE`), enforces `720×520` minimum window dimensions, persists multi-monitor-validated window bounds, and exposes a native `MethodChannel('bistre/desktop_host')` for OS file pickers (`IFileOpenDialog`/`IFileSaveDialog`) and `ShellExecuteW` folder opening.
- **Workspace surfaces** (layout contract: `docs/design/DESIGN.md` §10):
  - **Sidebar** (`apps/bistre_app/lib/features/sidebar/folio_sidebar.dart`): docked at `>= 740px` (`Ctrl+B`), a `FolioDrawerFrame` drawer below; `Assistant | Chat | Pinned` switch, filter, date groups (`Today`, `Yesterday`, `Previous 7 days`, `Older`), hover/focus row actions, footer with `Settings` and the theme toggle.
  - **Shell** (`apps/bistre_app/lib/features/shell/`): header (`apps/bistre_app/lib/features/shell/folio_shell_screen.dart`), session tree (`apps/bistre_app/lib/features/chat/session_tree_overlay.dart`, `Ctrl+Alt+G`), Studio pane with `Runs`, `Files`, `Story`, and `Prompt` tabs (`apps/bistre_app/lib/features/studio/runs_dock_panel.dart`), chat parameters drawer (`apps/bistre_app/lib/features/inspector/chat_inspector_drawer.dart`), FTS5 search, and the `Ctrl+K` command palette.
  - **Settings** (`apps/bistre_app/lib/features/settings/`): a full-window workspace (`Esc` returns to the chat) with Providers & Keys, Assistants, Appearance, Safety & Budget, Agent/Tools & Sleep, Memory & Skills, Updates & Storage, Language, and Shortcuts.
  - **Chat** (`apps/bistre_app/lib/features/chat/`): `MarkdownFolioView` (GFM tables with Copy CSV/MD, `NotoSansMath` LaTeX in `math_folio_view.dart`, Mermaid in `mermaid_canvas_view.dart`, tinted code), collapsible reasoning, `ToolTimelineView` (diffs, inline approval, Rewind), reversible compaction cards, and `FolioComposer` (attachments, `@` mentions, `/` commands, steering queue, quoted replies, diagnostics).
  - **Story** (`apps/bistre_app/lib/features/story/`): `Write` mode adds the roleplay controls and `ManuscriptCanvas` (chapters, scenes, beats → prose, inline rewrite).
  - **Design layer** (`apps/bistre_app/lib/design/`): the 10 primitives in `ink_primitives.dart`; declared controls in `bistre_controls.dart` (`BistreSlider`, `BistreSwitch`, `BistreSegmentedControl`), `bistre_icons.dart`, and `bistre_motion_widgets.dart`.
  - **Visual gate**: `just ui-gallery` renders the gallery (`apps/bistre_app/test/ui_gallery_test.dart`, `ui_gallery_a11y_test.dart` for 200% text and icon clarity, `ui_gallery_review_test.dart` for split diff and the cost popup). Review the PNGs after every UI change.

## 3. v2.6.0 Craft Inheritance (Implemented; open gaps in §4)
- **One bold mark**: `rubricMark` / `kRubricMarkWidth` (`apps/bistre_app/lib/design/bistre_decorations.dart`) on the selected sidebar chat, active settings category, and empty-chat intro.
- **Recovery surfaces**: composer backoff notice with countdown and inline `Retry now` (`EngineClient::retry_run_now`); jump-to-fix chips for key/quota, conversation-limit (`Shorten the conversation`), and spending-limit errors; chat delete with an 8 s `Undo` toast (no confirmation step).
- **Large text**: `textScaledWidth` (≤ `1.6x`) sidebar and settings-nav widths; `BistreSettingRow` stacks `label / control` when width ÷ text scale < 480 px; composer toolbar splits into two rows and header actions stack (wrapping) when width ÷ text scale < 600 px at ≥ 130% / ≥ 135% text; segmented controls shrink with ellipsis instead of overflowing. Gallery: `apps/bistre_app/test/ui_gallery_a11y_test.dart` (`phone-text200`, `desktop-text200`, retry notice, 22 px + 12 px icon sheet).
- **Context gauge**: `ContextGaugeRing` (`apps/bistre_app/lib/features/chat/context_gauge_ring.dart`) shows core's estimate (`EngineClient::context_usage` → `ContextUsage`, ~4 characters per token) of what the next request sends for the visible branch: the system prompt, the Write-mode story prompt, and the history, with the same projection a run uses, so a compaction or context pin lowers it. `FolioController.contextUsage` asks again when the chat, the branch's newest node, or the pin changes, and a sequence number drops older answers. Only the gauge listens. The conversation-limit fraction appears only when a limit is known. Tapping the ring (or Enter/Space) opens the breakdown popover (v2.6.0 `ContextWindowBreakdownPopover`): a stacked bar and rows for instructions, story notes and cards, chat history (with the message count), the unsent draft (core recounts it on open), and free space, plus **Shorten the conversation** and **Prices**. Not yet: session cost, uploaded-file and tool-schema rows (no native tool calling yet), and a real tokenizer.
- **Profile name**: Settings > Appearance > Profile holds `AppSettings.user_display_name`. It labels the user's messages, and core adds "The user's name is <name>." to the system prompt of every chat except Write mode, which brings its own persona (`engine_runs::with_user_name`: control characters dropped, 64 characters at most; the context breakdown counts it under instructions). Empty means nothing is shared. Not yet: the v2.6.0 profile picture.
- **Low-memory mode**: `detectLowMemoryHost()` (`apps/bistre_app/lib/platform/host_memory.dart`; Windows `GlobalMemoryStatusEx`, Linux `/proc/meminfo`, Android `ActivityManager.isLowRamDevice`) sets `BistreThemeData.reducedEffects` (no shadows) and a `33 ms` (30 fps) leaf redraw interval; probing never blocks startup.
- **Window caption**: `<chat title> — Bistre`, `Replying · <chat title> — Bistre`, or `Settings — Bistre` via the runner's `setWindowTitle` channel.
- **Accessibility**: modal/drawer overlays wrap the occluded shell in `ExcludeSemantics`; disabled `EngravedButton`s keep an outline and muted ink; focus rings appear only in keyboard highlight mode; `readableInk` nudges secondary/muted/accent/status inks to ≥ 4.5:1 on all four surfaces.
- **Split diff**: tool diffs render unified; when the timeline is at least `kSplitDiffMinWidth` (720 px) wide after dividing by the text scale, a `Split` / `Unified` toggle shows old | new columns. `pairSplitDiffRows` aligns each run of removals with the additions that follow; context lines appear on both sides and headers span both; diffs are always LTR.
- **Unavailable cost**: `NodeUsageMeta.costKnown` reads the node's `cost_known`. An unpriced reply shows no price, only a quiet `BistreUiIcon.info` button (`apps/bistre_app/lib/features/chat/cost_unavailable_button.dart`) whose popover explains that the reply counts as `$0` toward the daily limit and lists the model and token counts (Spec 06). Tests: `apps/bistre_app/test/diff_and_cost_test.dart`.

- **Thinking control (2026-11-24)**: the composer has a `Thinking: <level>` chip (`features/chat/thinking_control.dart`). It opens a popover above itself with a seven-stop `BistreSlider`: Auto, Off, Low, Medium, High, Extra, Max. This matches v2.6.0 `ThinkingControl`, which has six stops; Auto is extra, so the model decides. Settings and the chat inspector use the same stops (`kThinkingStops`).
