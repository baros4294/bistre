# Spec 08 — Custom Sepia Book UI (Pure `package:flutter/widgets.dart`)

## 1. Zero UI Libraries & Mechanical Enforcement
`apps/bistre_app` imports ONLY `package:flutter/widgets.dart` (plus `foundation`, `rendering`, `services`, `painting`). Importing `package:flutter/material.dart`, `package:flutter/cupertino.dart`, `package:material_ui`, `package:cupertino_ui`, `package:flutter_localizations`, `package:google_fonts`, third-party state frameworks, or direct HTTP/SQL libraries is a compile-time static analysis error enforced by `tools/bistre_lints` (`bistre_forbid_ui_kits`), alongside `bistre_forbid_hardcoded_ui_strings`, `bistre_forbid_layout_animations`, `bistre_forbid_raw_colors`, and `bistre_forbid_non_directional_geometry`. The layout-animation rule also rejects `SizeTransition`, `AnimatedCrossFade`, `AnimatedDefaultTextStyle`, and `AnimatedFractionallySizedBox`; the directional rule also rejects `Positioned(left:/right:)` and `TextAlign.left/right`. `just i18n-check` rejects internal or literary jargon in every locale and enforces the `DESIGN.md` §9 plain-language glossary in English. Visual tokens, typography, and the 10 Ink Primitives are governed exclusively by [`docs/design/DESIGN.md`](../design/DESIGN.md).

## 2. Pure-Widgets Ergonomics & Cross-Platform Controls
- **Root Shell**: `WidgetsApp` configured with explicit `color`, `textStyle`, `localizationsDelegates`, `locale`, `supportedLocales`, `builder` injecting `BistreTheme` + `BistreLocalizations` + `Directionality`.
- **Selection & Cross-Span LaTeX Copy**: Wrap thread feeds in `SelectableRegion` with custom `BistreSelectionControls` (copy / select all toolbar rendered via `FolioOverlay` / `OverlayPortal`, zero Material toolbar). Every LaTeX widget wraps inside `SelectionContainer.disabled` + a custom `Selectable` (`BistreMathSelectable`) returning verbatim `$...$` / `$$...$$` source text on sweep copy (preventing Flutter `WidgetSpan` drop bug `#160510` & flicker `#179527`).
- **IME Composition Safety**: `QuillInput` wraps `EditableText` directly, never modifies `controller.text` while `controller.value.composing.isValid` (protecting Vietnamese Telex/VNI and CJK IME composition), never sets `enableSuggestions: false` on prose inputs, and uses `Characters` grapheme indexing.
- **Live-Stream Scroll & Leaf Streaming**: the feed is a full-width `CustomScrollView` whose items each center a `ConstrainedBox(maxWidth: readingWidth)` (`_ReadingColumn`), so the mouse wheel scrolls from the empty page margins; a chat opens anchored at its newest message; `UserScrollNotification` unpins auto-follow on manual upward scroll and re-pins within `24px` of the tail. Stream deltas update only `LiveTurnNotifier` (`apps/bistre_app/lib/features/shell/live_turn_notifier.dart`), read by the single streaming item through a `ValueListenableBuilder` inside a `RepaintBoundary`; `FolioController` (shell, header, sidebar) is not notified per delta (regression-tested in `apps/bistre_app/test/anti_pattern_regression_test.dart`).
- **Code Fences & Inline SVG Preview**: soft-wrap follows `AppSettings.code_wrap_mode` (`auto` wraps below 640 px, `on`, `off`) with a per-fence toggle kept in `CodeWrapScope` so it survives virtualization. Fences render as independent `kCodeChunkLines` (8-line) chunks, each a highlighted `Text.rich` behind its own `RepaintBoundary`; while a reply streams, finished chunks keep the identical widget instance, so only the growing tail chunk is re-highlighted, laid out, and repainted. Highlighting runs per chunk, so a block comment or string spanning a chunk boundary is tinted per chunk (the source text, selection, and copy stay exact). `MarkdownFolioView` keeps up to four open-fence parse memos (`apps/bistre_app/test/streaming_markdown_test.dart`). Fenced `svg` blocks also offer an offline `Preview` / `Source` toggle backed by a safe pure-Dart vector painter (zero scripts or network fetches).
- **Android 15/16 Edge-to-Edge**: `MainActivity.kt` invokes `WindowCompat.setDecorFitsSystemWindows(window, false)`; `BistreScaffold` maps physical `MediaQuery.paddingOf(context)` left/right cutouts according to `Directionality.of(context)` (preventing RTL cutout inversion) and computes bottom avoidance via `max(MediaQuery.paddingOf(context).bottom, MediaQuery.viewInsetsOf(context).bottom)` so bottom chrome never jumps when floating/docked keyboards open.
- **State Management**: Built-in `ChangeNotifier` / `ValueNotifier` + `InheritedNotifier` + `ListenableBuilder` only (zero third-party state frameworks). The root `WidgetsApp` listens only to `FolioController.appearance` (an `AppAppearance` value: theme, accent, typography, reduced effects) and the locale, and reuses the resolved theme until that value changes; the window title follows the controller through a listener. Toasts, search (query, scope, results), the Draft saved label, and the sidebar filter each have their own notifier read only by the widget that shows them, so none of them rebuilds the shell; the engine's draft-saved echo changes nothing and notifies nothing. Thread switches carry a generation number and search carries a sequence number (150 ms debounce), so a slower, older response never replaces newer state. Chats still inside their Undo window are deleted when the app pauses or closes. Committed markdown is parsed once per text (256-entry LRU in `MarkdownFolioView`), and messages never replay an entrance animation. Tests: `apps/bistre_app/test/anti_pattern_regression_test.dart`.
- **Plain Everyday Copy & Vertical-First Restraint**: User-facing strings across `en`, `vi`, and `ar` strictly use everyday language (`Send`, `New chat`, `Recent`, `Pinned`, `You`, `Light`/`Dark`, `Document`/`Bubbles`, `Settings`, `Providers & Keys`). Navigation, providers, assistants, topics, chats, and settings compose from clean vertical lists, reserving horizontal segmented tracks strictly for 2–4 compact mutually exclusive toggles.
- **Windows 11 Native Desktop Host (`apps/bistre_app/windows/runner/`)**: Uses a true native Win32 frame (`Bistre`) with DWM Sepia titlebar tinting (`DWMWA_CAPTION_COLOR`, `DWMWA_TEXT_COLOR`, `DWMWA_BORDER_COLOR`, `DWMWA_USE_IMMERSIVE_DARK_MODE`, `DWMWCP_ROUND`), `WS_CLIPCHILDREN | WS_CLIPSIBLINGS` composition hygiene (no `CS_HREDRAW | CS_VREDRAW`, `SWP_NOREDRAW` resize without GDI erase flicker after first visible frame), Skia GLES renderer default (`ImpellerSwitch::Disabled`, opt-in `BISTRE_IMPELLER=on` override) to avoid ANGLE/D3D11 tearing under `SwapEffectUpgradeEnable`, deferred first-frame reveal + `ForceRedraw()` after visible (zero blank launch/maximize frames), live `onWindowBoundsChanged` multi-monitor persistence (skipping redundant bounds calls), `720×520` minimum window dimensions, and a native `MethodChannel('bistre/desktop_host')` for OS file/folder pickers (`IFileOpenDialog`/`IFileSaveDialog`), `ShellExecuteW` folder opening, `Shell_NotifyIconW` system tray & completion notifications, and `HKCU` auto-start.
- **Workspace surfaces** (layout contract: `docs/design/DESIGN.md` §10):
  - **Sidebar** (`apps/bistre_app/lib/features/sidebar/folio_sidebar.dart`): docked at `>= 740px` (`Ctrl+B`) with `RepaintBoundary`-isolated VSYNC spring slide (`SidebarSlideReveal`), a `FolioDrawerFrame` drawer below; `Assistant | Chat | Pinned` switch (`Chat` and `Pinned` virtualized via `ListView.builder` so 300+ chats render lazily), filter, date groups (`Today`, `Yesterday`, `Previous 7 days`, `Older`), hover/focus row actions, footer with `Settings` and the theme toggle.
  - **Shell** (`apps/bistre_app/lib/features/shell/`): header (`apps/bistre_app/lib/features/shell/folio_shell_screen.dart`), slim top `FolioTopBanner` for update/status notices, centered pill `FolioToastBanner`, optional wide-screen `SplitSecondaryPane`, session tree (`apps/bistre_app/lib/features/chat/session_tree_overlay.dart`, `Ctrl+Alt+G`), on-demand Studio pane (`Runs`, `Files`, `Story`, `Prompt`), chat parameters drawer (`apps/bistre_app/lib/features/inspector/chat_inspector_drawer.dart`), FTS5 search, and the `Ctrl+K` command palette.
  - **Settings** (`apps/bistre_app/lib/features/settings/`): a full-window workspace (`Esc` returns to the chat) with Providers & Keys (strictly Big 3 — OpenAI, Google Gemini, Anthropic — plus Custom OpenAI-compatible; Multi-API-Key rotation + Advanced & Model Settings sub-pages), Default Models, Assistants, Appearance (Chat display, Message nav rail, Code syntax theme preview, Behavior & Global instructions, Desktop App controls), Safety & Budget (4 Trust Presets: `Off` / `Strict` / `Balanced` / `Sandbox`), Agent, Tools & Sleep (native multi-folder picker + Git branch badge, MCP Add/Import JSON, DuckDuckGo search, opt-in Computer Use, Sleep Survival), World Book & Cards, Memory & Skills, Updates & Storage, Language, and Shortcuts.
  - **Chat** (`apps/bistre_app/lib/features/chat/`): `MarkdownFolioView` (GFM tables with Copy CSV/MD, `NotoSansMath` LaTeX in `math_folio_view.dart`, Mermaid in `mermaid_canvas_view.dart`, inline SVG preview, tinted code), collapsible reasoning, `ToolTimelineView` (collapsible Agent Step Checklist, diffs, shell compound step breakdown, inline approval, Rewind), `MessageNavRail` (floating trail + filterable Message Map), reversible compaction cards, `ChatOverlays` (Pinned replies, Chat notes, Turn details with citations & raw metadata, Attachment viewer), and `FolioComposer` (attachments, Tools popover with Mode + 4 Trust Presets + native folder picker + Web search + Prefill, VSYNC spring `ThinkingControl` slider + Adaptive/Automatic + custom effort, vertical keyboard-navigable `@`/`/` `ComposerTriggerMenu`, steering queue, quoted replies, diagnostics).
  - **Story** (`apps/bistre_app/lib/features/story/`): `Write` mode adds the roleplay controls and `ManuscriptCanvas` (chapters, scenes, beats → prose, inline rewrite).
  - **Design layer** (`apps/bistre_app/lib/design/`): the 10 primitives in `ink_primitives.dart`; declared controls in `bistre_controls.dart` (`BistreSlider`, `BistreSwitch`, `BistreSegmentedControl`), `bistre_icons.dart`, and `bistre_motion_widgets.dart`.
  - **Visual gate**: `just ui-gallery` renders the gallery (`apps/bistre_app/test/ui_gallery_test.dart`, `ui_gallery_a11y_test.dart` for 200% text and icon clarity, `ui_gallery_review_test.dart` for split diff and the cost popup). Review the PNGs after every UI change.

## 3. Interaction Craft & Surfaces
- **One bold mark**: `rubricMark` / `kRubricMarkWidth` (`apps/bistre_app/lib/design/bistre_decorations.dart`) on the selected sidebar chat, active settings category, and empty-chat intro.
- **Recovery surfaces**: composer backoff notice with countdown and inline `Retry now` (`EngineClient::retry_run_now`); jump-to-fix chips for key/quota, conversation-limit (`Shorten the conversation`), and spending-limit errors; chat delete with an 8 s `Undo` toast (no confirmation step); instant non-destructive reply regeneration with an 8 s non-blocking toast (`Previous`) that cancels and restores the prior sibling branch in one click.
- **Large text**: `textScaledWidth` (≤ `1.6x`) sidebar and settings-nav widths; `BistreSettingRow` stacks `label / control` when width ÷ text scale < 480 px; composer toolbar splits into two rows and header actions stack (wrapping) when width ÷ text scale < 600 px at ≥ 130% / ≥ 135% text; segmented controls shrink with ellipsis instead of overflowing. Gallery: `apps/bistre_app/test/ui_gallery_a11y_test.dart` (`phone-text200`, `desktop-text200`, retry notice, icon clarity sheet).
- **Context gauge**: `ContextGaugeRing` (`apps/bistre_app/lib/features/chat/context_gauge_ring.dart`) shows core's offline BPE count (`EngineClient::context_usage` → `ContextUsage`, `crates/bistre-core/src/tokenizer.rs` via `tiktoken 5.1.1` universal `o200k_base`) of what the next request sends for the visible branch: the system prompt, the Write-mode story prompt, and the history, with the same projection a run uses, so a compaction or context pin lowers it. `FolioController.contextUsage` asks again when the chat, the branch's newest node, or the pin changes, and a sequence number drops older answers. Only the gauge listens. Tapping the ring (or Enter/Space) opens the breakdown popover: session spend (`Session $X`), stacked bar, rows for instructions, story notes and cards, chat history (with message count), unsent draft (core recounts on open), attached files count, and free space, plus **Shorten the conversation** and **Prices**.
- **Per-turn usage details pill**: `UsageDetailsPill` (`apps/bistre_app/lib/features/chat/usage_details_pill.dart`) makes each assistant reply's token/cost footer interactive: hover hint on pointer rest, and tap/Enter/Space opens a breakdown card with model, provider, input tokens, cached read/write tokens, reasoning tokens, output tokens, TTFT, duration, output speed (`tok/s`), and cost (or unavailable-cost status).
- **Tab switcher & cross-provider model picker**: `TabSwitcherModal` (`apps/bistre_app/lib/features/shell/tab_switcher_modal.dart`) opens from desktop `ChatTabStrip`'s `N tabs` button or phone header's compact tab badge, with 1-col/2-col responsive grid, filter above 3 tabs, `Close N empty` bulk cleanup, `StreamingPulseDot` on streaming tabs, `Ctrl+Tab`/`Ctrl+Shift+Tab` cycling, and Android back dismissal. `ModelPickerPopover` (`apps/bistre_app/lib/features/shell/model_picker_popover.dart`) unifies all providers with search (`Enter` picks top match), provider filter chips, slash-prefixed family filter chips, active-model pinning, and `On device`/`Cloud` + `Stored`/`No store` badges.
- **Profile name & avatar**: Settings > Appearance > Profile holds `AppSettings.user_display_name` (which labels user messages and injects `"The user's name is <name>."` into non-Write system prompts via `engine_runs::with_user_name`) and an optional local profile picture picker.
- **Composer tools & thinking**: `ComposerToolsControl` (`features/chat/composer_tools_control.dart`) opens an above-anchor popover showing Mode (`Chat`/`Plan`/`Build`/`Write`), 4 Tool permission presets (`Off`/`Strict`/`Balanced`/`Sandbox`), native folder picker, web search toggle (DuckDuckGo default), and optional assistant reply start (prefill). `ThinkingControl` (`features/chat/thinking_control.dart`) offers a smooth VSYNC spring `BistreSlider` plus `Adaptive`/`Automatic` quick chips and a custom effort input.
- **Chat overlays**: `PinnedRepliesModal`, `ChatNotesModal`, `TurnDetailsModal` (web citation links + raw metadata JSON), and `AttachmentViewerModal` (`features/chat/chat_overlays.dart`) trap focus and dismiss cleanly via Escape or Android back.
- **Per-chat budget, 4 trust presets & MCP import**: Settings > Safety & Budget provides 4 trust presets (`Off` / `Strict` / `Balanced` / `Sandbox`) and an optional per-chat spending limit override; Settings > Agent, Tools & Sleep provides per-tool `Ask / Allow / Off` permissions, native multi-folder picker + Git branch badge, Add server + safe `Import MCP JSON` (`enabled: false`, Android command stripping), and Background & Sleep Survival controls; `ToolTimelineView` breaks compound shell commands into readable numbered steps (display-only; permits always bind raw arguments).
- **Low-memory mode**: `detectLowMemoryHost()` (`apps/bistre_app/lib/platform/host_memory.dart`; Windows `GlobalMemoryStatusEx`, Linux `/proc/meminfo`, Android `ActivityManager.isLowRamDevice`) sets `BistreThemeData.reducedEffects` (no shadows) and a `33 ms` (30 fps) leaf redraw interval; probing never blocks startup.
- **Window caption**: `<chat title> — Bistre`, `Replying · <chat title> — Bistre`, or `Settings — Bistre` via the runner's `setWindowTitle` channel.
- **Accessibility**: modal/drawer overlays wrap the occluded shell in `ExcludeSemantics`; disabled `EngravedButton`s keep an outline and muted ink; focus rings appear only in keyboard highlight mode; `readableInk` nudges secondary/muted/accent/status inks to ≥ 4.5:1 on all four surfaces.
- **Split diff**: tool diffs render unified; when the timeline is at least `kSplitDiffMinWidth` (720 px) wide after dividing by the text scale, a `Split` / `Unified` toggle shows old | new columns. `pairSplitDiffRows` aligns each run of removals with the additions that follow; context lines appear on both sides and headers span both; diffs are always LTR.
- **Unavailable cost**: `NodeUsageMeta.costKnown` reads the node's `cost_known`. An unpriced reply shows no price, only a quiet `BistreUiIcon.info` button (`apps/bistre_app/lib/features/chat/cost_unavailable_button.dart`) whose popover explains that the reply counts as `$0` toward the daily limit and lists the model and token counts (Spec 06). Tests: `apps/bistre_app/test/diff_and_cost_test.dart`.

## 4. Responsive & Interaction Matrix
Every primary surface is verified across desktop (`>= 720 dp`), phone (`< 720 dp`), `200%` text scaling, and RTL (`ar`) via `just ui-gallery` and widget regression tests:

| Surface | Desktop (`>= 720 dp`) | Phone (`< 720 dp`) & Large Text (`200%`) |
|---|---|---|
| Header | Single bar: sidebar toggle, chat title + interactive `model on Provider` subtitle, new chat, Studio pane, Settings | Compact tab badge (`N tabs`), stacked/wrapped actions at `>= 135%` text, `48 dp` touch targets |
| Chat tabs | `ChatTabStrip` with `+`, `N tabs`, `StreamingPulseDot`, `Ctrl+Tab` cycling, `TabSwitcherModal` with `Close N empty` | Compact header badge opening bottom-sheet `TabSwitcherModal` (1-col at `< 420` effective px), Android back dismissal |
| Messages & code | Bubbles or Document layout; hover/focus actions + right-click menu; code cards with wrap/fold/save/copy + inline SVG preview | Touch keeps action bar on newest turns; code auto-wraps below `640 px`; long-press stays reserved for text selection |
| Composer | Single toolbar row: attach, Tools popover, Thinking slider + custom, mode/assistant, `ContextGaugeRing`, quiet `Send` | Splits to two rows while streaming or at `>= 130%` text; ring hides number label under `600 px` while keeping semantic label |
| Settings | Left searchable navigation rail with matched-setting jump & highlight banner; full-width content cards; 9 theme preview cards | Vertical card list with summaries and matched labels, one page at a time, Android back & `72 dp` start-edge swipe back |
| Modals & drawers | Focus-trapped `FolioOverlay` with `ExcludeSemantics` on background, Escape dismiss, `Ctrl+K` palette | Bottom-sheet ergonomics, Android back closes innermost layer first before exiting |
