## 2. Principal Architect Pushbacks & Upgrades

1. **Provider State Defaults vs Local-First Sovereignty**: Gemini Interactions (`store=true`, 55d/1d) and OpenAI Responses (`store=true`, 30d) retain server state by default; Gemini makes `store=false` mutually exclusive with `previous_interaction_id`/`background=true`; OpenAI server-side compaction produces opaque ciphertext; Sept 2026 research (*The Compaction Cliff*, arXiv:2608.22752; *Compaction as Epistemic Failure*, arXiv:2607.13071) proves repeated lossy compaction erodes safety constraints and fabricates completion claims.
   - **Decision**: Default **`store: false`** across all dialects; persist `(provider_id, model_id, signature_blob)` reasoning signatures in SQLite and strip foreign signatures on model switch; treat server state IDs as opt-in disposable cache acceleration; perform local reversible branch-safe compaction with safety rules & verification receipts pinned outside summaries.
2. **MCP `2026-07-28` Stateless Rewrite**: Adopt official `rmcp 3.11.0` auto-negotiating `server/discover` (`2026-07-28`) → `2025-11-25`/`2025-03-26` legacy fallback; omit deprecated Roots/Sampling/Logging/HTTP+SSE; quarantine non-JSON stdio `stdout` noise.
3. **Runtime Hot-Loadable ICU i18n without Material**: Standard Flutter `gen-l10n` cannot hot-load OTA locale packs and `flutter_localizations` pulls Material/Cupertino. Replaced with single-source `l10n/catalog/*.bistre-l10n.json` metadata catalog + `tools/bistre_i18n` validator/typed `L10nKey` generator + pure-Dart runtime ICU MessageFormat evaluator + CLDR plural rules.
4. **Pure `widgets.dart` & First-Party Dart Analyzer Plugin**: `SelectionArea`/`TextField`/`Scaffold` live in Material; build on `WidgetsApp`, `SelectableRegion` + custom `BistreSelectionControls`, `EditableText`, `RawScrollbar`, `OverlayPortal`, enforced natively inside `flutter analyze` via `tools/bistre_lints` (`analysis_server_plugin 0.3.26`).
5. **FRB v2 Native Assets over Cargokit**: Cargokit broke on AGP 9 / Gradle 9.1 (`#3300`). Adopted `flutter_rust_bridge 2.13.0` + `flutter_rust_bridge_hooks` (`hook/build.dart`) with pinned `rust-toolchain.toml` (`crates/bistre-ffi/rust-toolchain.toml` required by `native_toolchain_rust 1.1.1`) and flattened zero-`freezed` FFI event DTOs decoded to Dart 3 `sealed class`.
6. **Resident `bistre-daemon` over Hidden Flutter Window**: Closing desktop window exits Flutter GUI completely (0 MB GPU/Impeller idle RAM) while `bistre-daemon` stays resident (`5.82 MB` measured RSS on Windows) owning SQLite WAL, active runs, Wayland clipboard, and `ksni`/Win32 tray behind one `EngineClient` trait.
7. **Pure-Rust `minisign-verify` Side-by-Side OTA over Velopack**: Velopack lacks native Ed25519 manifest signing (`#975`, `PerformanceMonitor#3288`) and requires .NET tooling. Pure-Rust `bistre-updater` (`206 KB` release binary) provides offline Ed25519 verification, 3-boot crash-loop auto-rollback, and Linux Flatpak/Snap/`/usr` detection; Android publishes a single direct GitHub `arm64-v8a` APK (`ADR-0008`).
8. **Git Worktrees**: `gix 0.89.0` for zero-fork read-only repo/status/diff + guarded `git worktree` (with CoW/hardlink scratch fallback when `git` absent or on Android).
9. **Remote Bridge Transport**: TLS 1.3 mTLS WebSocket over TCP (QR-exchanged leaf cert fingerprint pin) over raw UDP QUIC to avoid enterprise UDP drops and Tailscale WireGuard MTU fragmentation.
